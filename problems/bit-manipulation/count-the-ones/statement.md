Report how many bits of `value` are `1` when it is written in binary.

## Input

- `value` — a non-negative integer

## Output

The number of `1` bits.

## Constraints

- `0 <= value <= 2147483647`

## Examples

### Example 1

Input: `value = 11`

Output: `3`

11 is `1011`.

### Example 2

Input: `value = 0`

Output: `0`

### Example 3

Input: `value = 2147483647`

Output: `31`

The largest value here is thirty-one `1`s.
