Report whether `value` is a power of two — that is, whether it equals `2^k` for
some whole `k` of zero or more.

`1` is a power of two, being `2^0`. Zero and negative numbers are not.

## Input

- `value` — an integer

## Output

`true` if `value` is a power of two, `false` otherwise.

## Constraints

- `-2147483648 <= value <= 2147483647`

## Examples

### Example 1

Input: `value = 16`

Output: `true`

### Example 2

Input: `value = 1`

Output: `true`

`2^0`.

### Example 3

Input: `value = 0`

Output: `false`
