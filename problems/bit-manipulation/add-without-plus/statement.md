Add two integers without using `+` or `-` anywhere in your solution.

Everything else is allowed: the bitwise operators, shifts, comparisons, loops.

## Input

- `first` — an integer
- `second` — an integer

## Output

Their sum.

## Constraints

- `-10^9 <= first, second <= 10^9`
- The sum fits in a signed 32-bit integer.

## Examples

### Example 1

Input: `first = 1`, `second = 2`

Output: `3`

### Example 2

Input: `first = -2`, `second = 3`

Output: `1`

### Example 3

Input: `first = 0`, `second = 0`

Output: `0`
