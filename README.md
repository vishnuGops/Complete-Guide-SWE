# DevProMax

DevProMax is a local-first, LeetCode-style training app for DSA interview prep in Python and Java, with a built-in LLM coach that reviews every run and submission.

Status: the server is in place — problem format, judge, persistence and the local HTTP API, with three pilot problems. The web UI, the LLM coach and the full catalogue are next (see ROADMAP.md).
