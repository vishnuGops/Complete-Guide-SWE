# DevProMax

DevProMax is a local-first, LeetCode-style training app for DSA interview prep in Python and Java, with a built-in LLM coach that reviews every run and submission.

Status: the loop works end to end — 20 validated problems, a local judge for Python and Java, the API, and a web UI where you can open a problem, write a solution and submit it. The LLM coach, the learning features and the full 200-problem catalogue are next (see ROADMAP.md).

```
npm install
npm run dev      # web on 127.0.0.1:5173, server on 127.0.0.1:5174
```
